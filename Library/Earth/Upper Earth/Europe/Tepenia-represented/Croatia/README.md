# Croatia

**What this is:** the Culture Library entry for Croatia, a culture-nation of Upper Earth. It holds the *results* of the DCI research (how this culture understands each concept), not the method (Derivation Mechanisms) and not the springboards.

- **Springboards (starting points, not results):** `Springboarding/Targets/Europe/Croatia/Springboards/`
- **Lands:** see the tracker in that folder (`PROGRESS TRACKER.md`); the author settles them in Stage 0.

## Layout
- `00 - Real-world baseline/`: the culture as the research finds it in the real world, before 2083.
- `01 - First Interwar (2083-2564)/`: how it diverged until the exiles left for Tepenia (the DCI's Stage 6, divergence).

Inside each era folder, one subfolder per sign (`01 - Aries/` to `12 - Pisces/`, plus `00 - Domain` notes as needed), one file per concept, mirroring the springboards. Nothing is filled in yet.
