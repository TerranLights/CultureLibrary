# Jupiter

This establishes regional cultures in orbit around Jupiter. Additionally, this forms the foundational progenitive basis for neocultures in orbit around Saturn, and then later-still in the Alpha/Proxima Centauri System.

## Appearance in Media

The primary works of media that will draw their data from this sub-library are:
